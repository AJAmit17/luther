Your agents. Your Mac. Anywhere.

Luther lets your phone drive the coding agents on your Mac. Start a task, answer what it asks, review the changes, and open the pull request from wherever you are. The code and the agents’ logins stay on the Mac.

Reach your Mac from any phone

Pick one. Every request between the phone and the Mac is end-to-end encrypted on all of them, and the phone needs nothing else installed.

Set it up in three steps

Luther is pre-release: the server and the apps are built from source. You need Go 1.26 and at least one agent CLI, logged in on the Mac.

  1. Build the server

    Or use the install script in the repository.

    git clone https://github.com/AJAmit17/luther.git
cd luther/server && go build -o luther .

  2. Start it and choose a way in

    luther stop closes every way in again; luther doctor says what’s missing.

    luther start
luther funnel          # or: luther tunnel --quick

  3. Install the app and pair

    Build the iPhone app with Xcode or the Android APK with Gradle, then scan the code Luther shows. The code works once and expires in minutes.

    luther pair

What you can do from the phone

The same sessions you’d have at the desk, not a copy of them.

Keep a session going
Stream the answer, queue the next message, stop a turn, or resume a session you started at the Mac.
Answer what the agent asks
Approve a command, answer its questions, accept a plan. Change permissions, model and effort at any time.
Review the work
Browse files, read each turn’s changes, then commit, push and open a pull request with the Mac’s own tools.
Open a terminal
A tmux terminal that survives a dropped connection and that you can pick up on the Mac.
Send photos and speak
Take a picture of the bug or dictate the task. Large photos are shrunk before the agent sees them.
See what it costs
Token use over 7, 30 and 90 days, per agent and model, with the costs the agents report.

Your Mac stays yours

No Luther-hosted relay and no database in the cloud. Pair only phones and people you trust: an agent can run commands and change files.

  • Luther listens only on 127.0.0.1; tunnels and Tailscale pass traffic to it.
  • A paired phone seals every request and event with X25519, HKDF-SHA256 and AES-256-GCM, so a leaked token alone can’t drive the Mac.
  • Removing a phone in Settings closes its connections within seconds.
  • File, Git and terminal routes stay inside your home folder and never reach ~/.ssh, ~/.aws, ~/.gnupg or your keychains.
  • Photos and logs on the Mac clean themselves up: uploads after three days, the server log capped at 5 MB.
